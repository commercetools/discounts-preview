# Contributing

This is a commercetools-labs project, provided as-is and unsupported (see [SUPPORT.md](SUPPORT.md)).
Contributions are welcome but reviewed on a best-effort basis.

1. Fork the repository and create a branch.
2. `cd merchant-center-custom-application && yarn install`.
3. Copy `.env.example` to `.env` and fill in your own values. Never commit `.env`.
4. Make your change and run `yarn start` to check it against a project of your own.
5. Open a pull request describing what changed and why.
